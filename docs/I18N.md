# Public-site localization

The public site uses the `lv`, `ru`, and `en` URL prefixes. Latvian is the default language:

- `/lv`
- `/ru`
- `/en`

The middleware rewrites localized public URLs to the existing App Router pages and redirects old unprefixed public URLs to `/lv`. Protected `/portal`, `/admin`, and `/dashboard` routes are not localized by this layer.

## Add a shared string

Add the key to the `SharedCopy` type and all three records in `apps/web/lib/i18n.ts`. Use `sharedCopy[locale]` from server components or pass the selected copy into a client component. Keep client components independent from `next/headers`; server-only locale access lives in `apps/web/lib/i18n-server.ts`.

## Add page content

Keep one route and one component. Read the locale with `getLocale()` and select translated content by stable keys. Do not duplicate a page for every language. `apps/web/lib/solution-localization.ts` contains the current public solution-card translations.

## Add a language-specific image

Place optimized WebP files under `apps/web/public/images`, select them explicitly by locale, and keep real `width`/`height`, an accurate localized `alt`, `sizes`, and a full-size accessible link. The Trade Management page demonstrates this pattern with the `avantime-ut-1-3-overview-{lv,ru,en}.webp` assets.

## Add a language

Extend `locales`, `localeNames`, `SharedCopy`, and every locale resource. Update the middleware locale matcher, language switcher, metadata alternates, and all localized image maps. Add direct-route and missing-translation checks before release.
